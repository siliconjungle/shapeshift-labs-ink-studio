# Dialogue sources

These are synthetic scratch takes made for *The Water Above*. They contain
original lines read by the macOS Samantha voice and captured to 32 kHz
mono WAV. The benchmark reads the WAVs directly.

- `fan-line.wav` — “Switch the fan off.”
- `water-line.wav` — “Listen. The water is above us.”

The production runner copies the untouched reads into the session package.
