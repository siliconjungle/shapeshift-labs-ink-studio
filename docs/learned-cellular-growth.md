# Learned cellular growth

`KIT.cellular.learned` loads the weights of a small neural cellular rule. Each
cell applies the same network to the state in its 3×3 neighborhood. The
bundled Harbor Mark rule grows an original two-color ornament from one seed
and repairs damage from the state that survives around the cut. The model
file carries the shared weights and the seed vector.
[Mordvintsev et al., Growing Neural Cellular Automata](https://distill.pub/2020/growing-ca/)

```js
const L = K.cellular.learned;
const model = L.compile(require('./examples/learned-harbor-mark.json'));
const sim = L.create({ model, width: 23, height: 23, seed: 12 });
sim.seedAt(11, 11);
sim.step(109);
const before = sim.frame();
const checkpoint = sim.checkpoint();
sim.erase({ at: [13.3, 6.8], radius: 4.1 });
sim.step(80);
const repaired = sim.frame().data('alpha');
```

## Version 1 model format

The runtime accepts JSON data in the browser and in Node. `compile(model)`
validates and copies the coefficients. A compiled model can be shared across
simulations. `create` also accepts the raw model object directly.

| Field | Meaning |
| --- | --- |
| `format`, `version` | `'ink-studio/neural-cellular'`, `1` |
| `channels` | 1–16 unique state channel names, in training order |
| `alpha`, `aliveThreshold` | Name of the life-mask channel and its strict neighborhood threshold, default `.1` |
| `perception` | Ordered subset of `identity`, `sobelX`, `sobelY`, and `laplacian` |
| `updateRate` | Probability a cell evaluates its residual update each tick, in `(0, 1]`, default `.5` |
| `seedState` | One starting value per channel. Its life-mask channel must exceed `aliveThreshold`. |
| `hidden` | `{ weights, bias }` for a dense ReLU layer with 1–128 outputs |
| `delta` | `{ weights, bias }` for a linear layer with one output per state channel |

Both weight tables are flat and output-major. Row `o` contains the weights
for output `o`. For `hidden`, the input is channel-major, with the selected
filters listed consecutively for each channel. For example, two channels with
`['identity', 'sobelX']` have inputs `[c0, sobelX(c0), c1, sobelX(c1)]`.
The Sobel filters use the 3×3 stencils divided by eight, with positive values
on the right for `sobelX` and on the bottom for `sobelY`. `laplacian` is the
mean of four cardinal neighbors minus the center.

Each tick reads the previous grid, applies the selected residual updates, then
commits together. The life mask keeps cells near alpha above the threshold in
both the input and the intermediate output. Cells outside the input life mask
remain zero during the update. The seed and tick determine which cells update,
so previews and exports can replay the same partial updates. State values
are signed Float32 and can exceed the display color range. Each batch has an
inference work budget and aborts atomically if the model produces a value
outside the bounded `[-64, 64]` state range.

## Author and replay

- `initial` accepts a packed cell-major state array or `({x,y}) => state`.
  The default is entirely zero. `seedAt(x,y)` writes the model's seed state
  into one cell. `edit([{x,y,state}])` writes full cell vectors.
- `erase({ at: [x,y], radius })` clears all channels in a circle, including
  the latent channels. Radius and center use cell-space coordinates.
  `boundary: 'wrap'` also wraps the eraser. The default `'empty'` supplies
  zero to neighborhood reads outside the grid.
- `frame()` retains an immutable view of the current tick. `data(name)` copies
  a channel plane, `get(x,y)` copies a cell vector, and `sample(name,u,v)`
  interpolates in chart coordinates. The default bounds are `[0, 1]` on
  each axis. `source(name, { bounds, project })` registers a world scalar
  for field views. Supply `sim` directly in `surfaceEffects.fields` to feed
  a projected material. Advance it before rendering, or provide retained
  frames for independent timeline seeks.
- `checkpoint()` copies the full state and update tick to JSON. Restore on a
  simulation with the same model, bounds, topology, and seed. Reapply later
  erasures at the same ticks for exact replay. `reset()` returns to the
  configured initial state.

## Train on artwork

[The optional PyTorch example](../examples/train-neural-cellular.py) trains a
23×23 grid with ten state channels and 48 hidden units. It takes transparent
artwork, grows samples from one cell, and trains over trajectories that
include circular erasures. The JSON written at the end of training contains
the shared rule and one seed vector. Inference and rendering run in
JavaScript in the browser and CLI.

```sh
python -m pip install torch numpy pillow
python examples/train-neural-cellular.py --target my-ornament.png --out my-ornament-rule.json
```

Omit `--target` to use the original Harbor Mark artwork generated by the
trainer. The bundled model was trained for 2,300 updates of the optimizer.
Regrowth quality depends on training, damage size, and surviving state.

## Render the studies

[Harbor Mark](../examples/learned-cellular-growth.js) builds the two-color
ornament, displays its opacity and first latent channel, then runs two cuts
on copies of a single grown checkpoint. Both cuts clear the full local state.

```sh
node cli/ink-studio.js clip examples/learned-cellular-growth.js --w 830 --h 520 --to 6.4 --fps 10 --out harbor-mark-growth.png
node cli/ink-studio.js clip examples/learned-cellular-growth.js --params '{"study":"repair"}' --w 830 --h 520 --to 6.4 --fps 10 --out harbor-mark-repair.png
```
